## Security research

- **Zcash / Zebra — High severity (CVSS 7.5), GHSA-7jp4-mq53-4cvq.** Reported a
  denial-of-service in Zebra, the Zcash Foundation's Rust node implementation: a
  quadratic (inputs × outputs) code path in the mempool coinbase-maturity check let a
  single unauthenticated peer pin a node's verification threads with one crafted
  transaction. Fixed in zebrad 7.0.0.
